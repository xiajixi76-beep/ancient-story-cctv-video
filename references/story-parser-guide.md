# 典故解析与剧情时间线设计指南

## 解析流程

拿到一个成语/典故后，按以下步骤拆解：

1. **确定核心场景**：这个故事发生在什么单一空间？（河边码头、宫廷庭院、山路、农田、书房等）
2. **确定关键人物**：谁是主角？谁是围观者？谁是执行者？
3. **确定关键道具**：什么物体的状态变化是视觉主线？（船、井、绳子、斧头、锤子等）
4. **拆成 4-6 个剧情节点**：每个节点必须有可见的状态变化，不能只是"对话"或"思考"
5. **分配时间**：总时长 30-60 秒，每个节点 5-10 秒

## 时间线设计模板

```
B01 (0-8s)：[开场事件] → [关键道具初始状态]
B02 (8-15s)：[主角介入] → [标记/准备动作]
B03 (15-28s)：[执行过程] → [关键道具状态逐渐变化]
B04 (28-35s)：[关键瞬间] → [状态到达目标点]
B05 (35-40s)：[结果呈现] → [围观者反应]
```

## 适配示例

### 曹冲称象（已验证）
- 场景：河边码头
- 关键道具：木船的吃水线
- 节点：大象上船船下沉 → 画标记线 → 大象下船上浮 → 搬石头上船 → 水位到标记 → 称石头

### 掩耳盗铃
- 场景：富户宅院门前
- 关键道具：门上的铃铛
- 节点：小偷鬼鬼祟祟走到门前 → 伸手碰铃铛响 → 捂住自己耳朵再碰 → 铃铛大声响 → 主人出来抓住小偷

### 守株待兔
- 场景：农田边树桩旁
- 关键道具：树桩和农具
- 节点：农夫在田里干活 → 一只兔子飞快跑过撞在树桩上死了 → 农夫捡起兔子很高兴 → 放下农具天天守在树桩旁 → 田地荒芜了 → 再也没有兔子来

### 刻舟求剑
- 场景：河上渡船中
- 关键道具：船舷上的刻痕
- 节点：古人坐船渡江 → 剑从身上掉进水里 → 在船舷上刻下记号 → 船靠岸后从刻痕处下水找剑 → 路人围观指点

## 设计原则

- **视觉优先**：每个节点必须能拍成画面，不能是纯心理活动或对话
- **单一空间**：全程不换场景，所有动作在同一个监控视角内发生
- **物理变化可见**：关键道具的状态变化（下沉、上升、移动、变形）是叙事主线
- **围观者反应**：每个故事都需要有一群围观的路人/官员/村民，他们的反应衬托主角行为的荒诞或聪明
