# 分段视频生成 Prompt 模板

## 分段策略

总时长超过 15 秒时必须分段生成。推荐每段 10-15 秒：

| 总时长 | 分段数 | 每段时长 |
|---|---|---|
| 15 秒以内 | 1 段 | 全部 |
| 16-30 秒 | 2 段 | 各 15 秒左右 |
| 31-45 秒 | 3 段 | 15s + 15s + 10-15s |
| 46-60 秒 | 4 段 | 各 15 秒左右 |

## 每段 Prompt 通用结构

每段 prompt 必须包含以下五个部分：

1. **参考图说明**：首帧参考图锁定了什么（视角、场景、人物、道具）
2. **监控风格全局设定**：固定机位、黑白画质、时间戳、CAM 01
3. **本段时间线动作**：具体描述这段视频里发生什么
4. **时间戳范围**：本段的起始时间
5. **声音与禁止项**：环境音描述、禁止出现的内容

## 单段 Prompt 模板

```
<参考图>是[场景名]监控画面的首帧基准，锁定高位俯拍视角、黑白监控画质、场景整体布局、关键道具位置、人物服饰和画面左上角时间戳、右上角CAM 01标识。

这是一段安装在[场景描述]高处的监控摄像头拍摄的真实录像。固定机位，高位俯拍向下倾斜约30度，全程不移动、不变焦、不切换角度。黑白监控画质，带有轻微颗粒噪点。所有人物和关键道具始终处于同一画面内。

[本段时间线动作，按秒数分段描述]：
- X-Y秒：[动作1的详细描述]
- Y-Z秒：[动作2的详细描述]

画面左上角持续显示白色老式监控数字字体时间戳"[起始时间]"，时间随播放逐秒递增。右上角持续显示"CAM 01"。字体轻微模糊，固定不动。

无旁白、无台词、无背景音乐。只有自然环境音：[列出本段的环境音：风声、水声、脚步声、工具声、动物叫声等]。

整体呈现真实监控录像的粗糙质感，没有电影灯光，没有戏剧化运镜，没有慢动作，没有特写。人物活动自然随意，像真实监控拍到的日常场景。
```

## 非首段的承接要求

第 2 段及以后的 prompt，必须在开头加上承接说明：

```
本段承接上一段末尾的状态：[上一段结束时的场景状态：人物在哪里、关键道具处于什么状态、时间戳到了多少]。
保持与上一段完全一致的机位、场景布局、人物服装和道具外观。
```

## 一致性检查清单

每段生成前确认：
- [ ] 机位高度和角度是否一致
- [ ] 场景布局（建筑、路面、道具位置）是否一致
- [ ] 人物服装和身份是否一致
- [ ] 关键道具外观是否一致
- [ ] 时间戳是否连续或有合理跳跃
- [ ] 黑白画质和颗粒感是否统一
- [ ] 没有切镜、没有运镜、没有特写
- [ ] 没有现代物品、现代建筑、现代服饰
